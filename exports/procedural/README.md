# 코드로 그린 그림 모음 (업그레이드용)

사용자가 준 그림(주인공, 상점 사람·배경, 입주자 초상화, 지층 바위·장식, 시작 화면·입구 그림)은 빠져 있고, 게임 코드가 직접 그리는 것만 들어 있어요.
`_x4` 폴더는 같은 그림을 4배로 키운 보기용이고, `_전체_모음.png`는 광물 아이콘을 뺀 나머지를 한 장에 모은 것이에요.

## 크기 기준
- 채굴 화면은 "월드 1px = 화면 2px"(폰 가로 360~390px 기준)로 그려요. 아래 "화면" 크기가 PNG 원본 크기예요.
- 새 그림을 주실 때는 화면 크기 그대로(또는 그 2배·4배 정수 배)로 주시면 도트가 번지지 않아요.
