## 완료 (v10) 대개편
- 용어: 합성 → 재련
- 하단 탭 6개: 채굴 · 장비 · 재련 · 장터 · 탑 · 관리 (관리 안의 장비는 빼서 따로)
- 장비 탭 = 마을 사람들의 공방 (src/equip.js). 초상화를 누르면 다른 대사
  - 무쇠네 대장간: 곡괭이 벼리기, 힘껏 내려치기(치명타 3배, 3%/단계), 쇠맥 찾기(금속 +1개 5%/단계), 보석 눈썰미(보석 +1개 5%/단계)
  - 핀의 작업대: 드릴 로봇, 로봇 보관함(200칸 ×1.6/단계), 자동 재련 장치(넘친 광석 판매 50% → 150%), 밤샘 근무(자리 비운 동안 +15%/단계)
  - 미르의 용광로: 풀무, 별빛 불씨(대성공 +1%), 자동 재련 칸(1→4), 센 불꽃(자동 재련 8초 → 빨라짐)
  - 셈 할멈의 창고: 창고 늘리기, 알뜰 정리(창고 가득 차면 가장 싼 원석을 팔아 자리 만들기), 월세 금고(월세 +4시간치/단계)
  - 루카의 정보소: 소문 감정, 흥정 솜씨(판매가 +1%/단계), 도매 거래처(대량 판매 하락 −12%/단계)
- 로봇 보관함: 별도 규격. 드릴은 창고 → 보관함 → 넘치면 원석 값 50%로 판매(자동 재련 장치로 올라감). 켜 둔 동안도 같은 규칙, 창고가 차도 드릴은 계속
- 자동 재련(재련 탭 위): 레시피를 미르에게 맡기면 시간이 지나며 알아서 재련, [계속]이면 재료가 들어오는 대로 계속. 자리 비운 동안에도 진행
- 디자인: 흙빛 테마로 복귀. 제목은 흙빛 돌 글씨 → 개척한 지층만큼 금이 가며 아래 오로라가 드러남, 엔딩 뒤 완전히 오로라. 탑 하늘 오로라도 깊이에 따라 짙어짐
- 상자 모서리: 3px 깎던 것을 1px로 → 테두리가 모서리까지 이어짐
- 그림: 주인공 2등신(큰 눈, 헬멧 등불, 빨간 목수건), 초상화 64×64(큰 눈, 반짝임), 지층 타일(돌 테두리 빛, 뿌리 · 버섯 · 결정 · 금가루 · 용암 · 유리), B11~13은 돌 틈으로 오로라
