## 완료 (v8) 광석 수량 재설계
- 곡괭이 위력 완만하게: l × (1 + l/20)
- 지층별 바위 체력을 봇으로 보정 → 켜 둔 채 초당 캐는 양: B1 약 1.9 → B5 1.4 → B9 1.0 → B13 0.78 (깊을수록 적게)
- 광석 1개 캐는 데 탭 횟수: B3 약 3 → B6 10 → B11 25 → B13 30~36
- 창고 시작 300칸 ×1.5/레벨 (비용 100 × 2.6^레벨), 로봇 보관함 = 창고 ×2, 비운 시간 8시간이면 가득
- 장터 규모 1 + 0.25×(지층−1) + 0.05×(완공 구간), 원석 4,000 / 합성품 2,000 / 별의 물질 1,200
- 창고 하나 분량 한 번에 팔면 −19%(초반) ~ −9%(후반)
- 봇 보정: 엔딩까지 39.3시간 (calib8.js, 목표 채굴 속도 RT 포함)
- 창고 가득 차는 시간: 초반 짧고 후반 길게(60~75분) 두기로 결정
- (v8.1) 오프라인 보상 비율 고정: 8시간 비우면 직접 플레이 1시간 30분치 (패키지 16시간까지), 보관함 한도도 같은 기준
